# Расписание — релизы Android

Публичные APK-релизы приложения «Расписание» для Android. Установочные файлы прикрепляются к GitHub Releases; версия и ссылка на текущий APK публикуются в `update.json`.

Приложение проверяет это описание обновления при запуске и по кнопке в настройках. Не публикуйте в репозитории исходники ключей подписи, keystore-файлы, пароли или токены.
